# cleaner-v1
Эта программа создана для быстрой очистки системы от временных файлов и кэша браузеров. Она помогает освободить место на диске и ускорить работу компьютера. Проект написан с нуля и использует библиотеку CustomTkinter для красивого, темного интерфейса.  ✨ Основные возможности Очистка временных файлов: Удаляет мусор из папок Temp
